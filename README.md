# Data-Professionals-Survey-Breakdown
This project analyzes survey responses from data professionals using Power BI, to understand salary trends, career satisfaction, work-life balance, and the challenges of entering the data industry.

## Dataset Used
[View Dataset](https://github.com/deeptipaiwork-oss/Data-Professionals-Survey-Breakdown/blob/main/Power%20BI%20Project%20Dataset.xlsx)

## Project Objectives
- Analyze survey data from data professionals to identify industry trends.
- Identify the most popular programming languages and tools used by respondents.
- Compare average salaries across different data-related roles.
- Analyze the geographical distribution of respondents.
- Examine respondent demographics, including average age.
- Understand how respondents perceive entering the data field.
- Clean and prepare the dataset for accurate analysis and visualization.

## Data Preparation I did
- Removed duplicate records
- Changed data types
- Split columns
- Renamed columns
- Handled null values
- Created calculated columns
- Created measures
- Standardized categories

## With 630 total survey takers, I designed a dashboard providing the following insights:
- Python is the most popular programming language.
- Among the different data roles, Data Scientists earn the highest average salary.
- USA has the largest number of respondents.
- Average respondent age is 30.
- Most respondents find entering the data field neither easy nor difficult.
